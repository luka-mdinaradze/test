# ბიტკოინის ფასის მთავარი ფაქტორები — და რომელი ჩანს TradingView-ზე

ფაქტორები დალაგებულია **გავლენის სიძლიერით**, და ყოველ მათგანზე მითითებულია
შეიძლება თუ არა Pine Script-ში გაზომვა. ეს განსხვავება მთავარია: დრაივერი,
რომელსაც ჩარტზე ვერ გაზომავ, ინდიკატორში ვერ შევა.

სვეტი „TV" ნიშნავს:
- **✅ ჩარტიდან** — ფასი/მოცულობიდან გამოითვლება
- **🔶 სხვა ტიკერით** — TradingView-ზე არსებობს, `request.security()`-ით ავიღებ
- **❌ გარე მონაცემი** — TradingView-ზე არ არის, API ან ხელით სჭირდება
